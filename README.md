# 🛒 Amazon Clone Project

An Amazon-inspired e-commerce website built using **HTML**, **CSS**, and **JavaScript**.
This project focuses on recreating the core UI and basic functionality of Amazon to practice front-end web development skills.

---

## 🚀 Features

* 🏠 Home page with product listings
* 🔍 Search bar UI
* 🛍️ Product cards with images, prices, and ratings
* ➕ Add to Cart functionality
* 🛒 Shopping cart page
* 🔢 Update item quantities
* 💰 Cart total price calculation
* 📱 Responsive design (basic)

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout (Flexbox / Grid)
* **JavaScript (ES6)** – Interactivity and logic
